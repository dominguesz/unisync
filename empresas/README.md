# UniSync Empresas beta — protótipo independente

Dois ambientes fictícios para demonstrar personalização corporativa: BASF e Scania. Nenhum login é necessário, não há integração com sistemas internos e todos os dados de interação são apenas locais ao navegador. As empresas citadas não patrocinam nem endossam o protótipo.

As páginas incluem sprints, cronogramas, mural, chats em grupo e perfis profissionais editáveis. Para testar, abra ./?empresa=basf ou ./?empresa=scania.
